# OVEC VDO (สถาบันการอาชีวศึกษา)

ระบบผลิตและตรวจภาพ Video Hook สำหรับสื่อการสอนอาชีวศึกษาด้วย Google Flow AI (Nano Banana 2.1)

## 📁 โครงสร้างโปรเจกต์
- `output/` — เก็บไฟล์บทเรียน, ไฟล์ภาพที่เจนแล้ว, และรายงานตรวจ (โฟลเดอร์นี้ถูกละเว้นใน Git เนื่องจากมีขนาดใหญ่)
- `rules/` — กฎระเบียบและเกณฑ์มาตรฐานสไตล์ภาพ (Style Bible, Technical Accuracy)
- `skills/` — ชุดทักษะและคำสั่งควบคุม AI สำหรับ Google Flow

## 🚀 สำหรับพนักงานในการใช้งาน
เมื่อมีการอัปเดตระบบ ให้ดึงเวอร์ชันล่าสุดด้วยคำสั่ง:
```bash
git pull
```
