# OVEC VDO (สถาบันการอาชีวศึกษา)

ระบบผลิตและตรวจภาพ Video Hook สำหรับสื่อการสอนอาชีวศึกษาด้วย Google Flow AI (Nano Banana 2.1)
โครงสร้างโฟลเดอร์และมาตรฐานอ้างอิงตามมาตรฐานกลางของ **OVEC-Agent**:

## 📁 โครงสร้างโฟลเดอร์ผลผลิต (Output Directory Convention)
```text
Output/<thaiName>/<CODE>/<CODE>_U<หน่วย>/<BASE>/
(ตัวอย่าง: Output/ไฟฟ้า/20104-2003/20104-2003_U2/20104-2003_U2_1/)
├── 1. เนื้อหา/
├── 2. แผนการจัดการเรียนรู้/
├── 3. Powerpoint/
├── 4. Video Hook/
│   ├── checkwork/
│   │   ├── image/                 # ไฟล์ภาพที่เจนแล้ว (Scene 01.jpg, ...)
│   │   ├── Checkwork_{BASE}_C1.json
│   │   └── Checkwork_{BASE}_C1.docx
│   └── {BASE}_C1.mp4              # ไฟล์วิดีโอสมบูรณ์
└── 5.exercise/
```
* **สาขา (`<thaiName>`):** `ไฟฟ้า` (ช่างไฟฟ้า) หรือ `อิเล็กทรอนิกส์`
* **รหัสบทเรียน (`<BASE>`):** `<CODE>_U<หน่วย>_<ลำดับ>` เช่น `20104-2003_U2_1`
